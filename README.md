# Bowerbird Official Plugins Distribution Repository

> ⚠️ This repository is automatically updated by GitHub Actions from the main Bowerbird repository. Do not edit directly.

This repository stores official Bowerbird plugin indices and release bundles.

- **`index.min.json`**: Compact JSON index of all available plugins and release download URLs.
- **`registry.json`**: Formatted JSON registry for debugging and documentation.
- **`repo/<id>/manifest.json`**: Individual plugin manifests.
- **Releases**: Pre-built `.zip` bundles containing `manifest.json` and bundled `index.js`.
